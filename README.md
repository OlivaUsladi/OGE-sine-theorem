Мобильное приложение для решения 15 задания ОГЭ по математике на теорему синусов. 
Есть возможность ввести углы, длины сторон треугольника, синусы углов треугольника. Рассчитываются по теореме синусов углы, длины сторон и радиус описанной окружности
